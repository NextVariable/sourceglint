# Sourceglint v0.2.1

Early research-first open-source release: discover recent source-linked information and user feedback, with GTM decisions available only when explicitly requested.

This release bundles runtime configuration and schemas in installed wheels, fixes host-only routing omissions, separates original-platform coverage from retrieval routes, preserves dated source excerpts and counterpoints, and handles long interactive JSON responses. A grounding guard now accepts a bounded disclaimer without allowing an affirmative universal claim to bypass validation.

Validation: 1657 offline tests pass; 10 live connector tests pass and 4 credentialed connectors are skipped. Real host-assisted discovery, feedback, no-evidence and nearby-corpus repeat artifacts are archived under docs/examples/2026-10-04. A clean installed-wheel smoke passes outside the repository.

This is an early release. It requires a capable host for search and reasoning; credentials are optional per source. Prior-window trends, representative coverage, external excerpt verification and broad GTM quality certification remain unavailable. No PyPI publication is claimed. MIT licensed.
