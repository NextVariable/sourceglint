# 文档导航

首次使用请阅读[项目首页](../README.md)，并查看[真实样例](examples/2026-10-04/README.md)。遇到来源无法访问的问题，可查阅[访问矩阵](source-access-matrix.md)和[降级说明](source-fallback-playbook.md)。[来源快照](source-live-status.json)记录的是指定日期的测试结果。

集成智能体时，查看[技能入口](../SKILL.md)和[交互协议](../references/host-protocol.md)。维护代码时，查看[架构说明](architecture.md)、[验证入口](validation.md)和[设计决策](adr/README.md)。

早期设计保存在[历史档案](archive/README.md)。`benchmarks/` 与 `reviews/` 保存各版本的审查记录，`evals/` 保存可复用的公开测试题。原始研究材料应保存在不提交的 `runs/` 中。

## English

Start with the [main README](../README.md) and [recorded examples](examples/2026-10-04/README.md). For unavailable sources, consult the [access matrix](source-access-matrix.md) and [fallback guide](source-fallback-playbook.md). The [source snapshot](source-live-status.json) records tests from a specific date.

For integrations, read the [Skill entry](../SKILL.md) and [host protocol](../references/host-protocol.md). For maintenance, see [architecture](architecture.md), [validation](validation.md) and [design decisions](adr/README.md).

Earlier designs remain in the [archive](archive/README.md). `benchmarks/` and `reviews/` retain version-specific evaluations; `evals/` contains reusable public cases. Keep raw research material in ignored `runs/`.
